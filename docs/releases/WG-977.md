# Release note: WG-977, advisory fee disclosure letters for Wood Gundy clients

**Line of business:** Wood Gundy
**Release:** 2026.10
**Files changed:** `src/lob/wood-gundy/letter-templates.js`, `src/lob/wood-gundy/disclosure.js`, `src/lob/wood-gundy/index.js`, `src/server.js`, `tests/wg-disclosure.test.js`, `regression/catalog.json`, `package.json`, `package-lock.json`

## Summary

Wood Gundy can now render advisory fee disclosure letters through `POST /api/advisory/:accountId/fee-disclosure`. Two letters are catalogued in `src/lob/wood-gundy/letter-templates.js` (`annual-fee-disclosure`, `fee-change-notice`) with their lodash template settings, and a request can instead carry a `draft` with its own template source and lodash `variable` setting. Rendering lives in `src/lob/wood-gundy/disclosure.js` (`_.template(source, { variable })`); `src/lob/wood-gundy/index.js` resolves the account, computes the letter figures, and rejects non-advisory accounts. The change introduces lodash as the platform's one runtime dependency. To keep the catalogue at 18 production-equivalent hours, the new `wg-disclosure` suite (60 min) is offset by rebalancing `ie-trading` from 180 to 120 min.

## Change impact

Compared against the 2026.09 release state.

**Regression scope:** 3 suites (smoke, wg-disclosure, wg-statements), 3.0 h of 18.0 h production-equivalent. The route touches `src/server.js`, so smoke runs; the letter code is reached from `src/lob/wood-gundy/index.js`, so wg-statements runs.

## Risks

- lodash is pinned at 4.17.20, which has known advisories (CVE-2021-23337, command injection through the `_.template` `variable` option, and CVE-2020-28500, ReDoS). The draft-letter endpoint passes a caller-supplied `variable` straight to `_.template`. Tracked in `security/findings/2026-10-22-sca.md`; the upgrade is planned as its own change. (High, known.)
- The API has no authentication, so a rendered letter is only as protected as the rest of the model (pre-existing; see SECURITY.md).

## Rollback

Restore the listed files from `.baseline/snapshot/` (or revert the merge commit) and remove the lodash dependency. No data, schema, or configuration changes are involved.
