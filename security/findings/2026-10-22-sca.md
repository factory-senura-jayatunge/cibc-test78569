## Reachable code path

SCA-1 is reachable from a request, not just present in the lockfile:

`POST /api/advisory/:accountId/fee-disclosure` → `feeDisclosureLetter` in `src/lob/wood-gundy/index.js` → `renderDisclosureLetter` in `src/lob/wood-gundy/disclosure.js` → `lodash.template(source, { variable })`. A draft letter in the request body supplies its own `variable`, which lodash 4.17.20 interpolates unvalidated into the compiled template function.
